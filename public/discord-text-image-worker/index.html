Live endpoint

This tiny Worker returns actual PNG responses from URL params. The first version only renders text, but it works well in Discord: short links, bold presets, predictable output, and cacheable results. 

https://tools.carter.works/text?text=THE%20BUILD%20HAS%20CHOSEN%20VIOLENCE&font=Bangers&align=center&bg=111827&color=facc15

Why a Worker?

  • Discord needs a real image URL. Client-side canvas does not help an unfurler.
  • The same URL can be cached at the edge after the first render.
  • Inputs can be clamped and normalized before rendering.
  • Future webhook versions can use secrets without exposing them to browsers.

Text endpoint

GET /text

Params:
text   required, max 180 chars
font   allowlisted Google Font
align  left | center | right
bg     6-digit hex
color  6-digit hex
w      320..1600, default 1200
h      180..1200, default 630
size   24..180, default auto
pad    16..160, default 72

Preset: incident

/incident?service=auth&cause=regex

Renders a fake outage card: SEV-2: auth was defeated by regex.

Preset: oracle

/oracle?repo=frontend

Returns a deterministic prophecy: CI will pass after 3 unrelated flakes.

Preset: blame

/blame?user=kyle&reason=force-pushed

Makes a lightly cursed accountability poster for the channel.

Implemented flow

  1. Parse params. Clamp image dimensions, text length, font size, padding, and colors before rendering.
  2. Normalize cache keys. Sort canonical params and include a template version so equivalent URLs share rendered output.
  3. Load fonts safely. Use an allowlist: Inter, Bangers, JetBrains Mono, Rubik Glitch, and Oswald.
  4. Render with Takumi. Build a small Takumi node tree for background, text color, alignment, wrapping, and typography.
  5. Cache rendered images. Store PNG responses in Cloudflare's cache and return long-lived immutable cache headers.
  6. Expose presets. Keep /text generic, with tiny route aliases for /incident, /oracle, and /blame.

Limits

This is intentionally not a general image editor. Text is capped, dimensions are clamped, fonts are allowlisted, and bad optional params fall back to safe defaults. Missing text returns a small JSON error.

What works

  • A pasted Discord URL unfurls as the generated PNG.
  • Same URL returns identical pixels and hits cache on repeat.
  • Bad params fall back or fail with a small JSON error.
  • The silly presets are deterministic, shareable, and safe to paste.

Example render shape

render(
  container({
    style: {
      width: "100%",
      height: "100%",
      display: "flex",
      alignItems: "center",
      justifyContent: align === "left" ? "flex-start" : align === "right" ? "flex-end" : "center",
      padding,
      backgroundColor: `#${bg}`,
    },
    children: [text(value, {
      color: `#${color}`,
      fontFamily: font,
      fontSize,
      fontWeight: 800,
      lineHeight: 0.95,
      textAlign: align,
    })],
  }),
  { width, height, fonts }
